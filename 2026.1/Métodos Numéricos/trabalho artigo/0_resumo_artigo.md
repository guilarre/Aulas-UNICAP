# 1. Image Encryption Algorithm Using Natural Interval Extensions - Nardo; Lima; Nepomuceno; Arias-Garcia

- na área de segurança da informação, existem muitos métodos de criptografia que fazem uso de um sistema caótico para gerar uma pseudo-aleatoriedade, que é então usada para criptografar.

- o problema disso é que há uma degradação de sistemas caóticos por conta da precisão finita, dos computadores.

- autor diz que nos últimos anos, tem-se tentado superar esse problema de diversas formas (ler ref de Cao et al. para um detalhamento dessas tentativas)

- autor propõe um método que explora essa limitação para formular algoritmos de criptografia

- usa extensão intervalar natural (maneira de utilizar funções com intervalos em vez de variáveis) pra resolver um sistema caótico
