1. Uma lista encadeada é uma estrutura de dados linear que organiza espaços não contíguos na memória em forma de lista, onde cada elemento aponta para o próximo elemento. É possível percorrer a lista até o fim através da referência ao próximo, chegando no último elemento, que aponta para NULL.

2. Um vetor é um espaço em memória contíguo, onde podemos percorrer através de aritmética de ponteiro/índice. Já na lista encadeada, não temos um espaço contíguo na memória. Cada elemento está em um espaço diferente e aponta para o próximo.
