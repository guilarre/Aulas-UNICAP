1. A pilha é uma estrutura de dados do tipo LIFO, onde o último elemento a ser inserido é o primeiro a sair. Funciona como uma pilha de objetos na vida real, onde o primeiro elemento inserido vai sendo bloqueado pelo próximo. Quando retiramos um elemento de uma pilha, vamos sempre ao topo primeiro.

Serve para modelarmos dados em forma aninhada e para implementarmos um tipo de gerenciamento automático da pilha através das funções pop, push, peek, etc., onde as operações são realizadas de uma maneira específica (sempre no topo) e não precisamos passar o índice para realizá-las.

2. A pilha pode ser usada para situações onde queremos gerenciar chamadas para funções, como na stack de um programa, reverter (desfazer) ações de um usuário ao longo do tempo, navegar em um histórico e organizar dados de forma aninhada, onde o elemento filho chama o pai, que chama o pai do pai, etc.
